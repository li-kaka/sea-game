# 海底城市・蘋果農場體驗原型

線上試玩：[https://fumoto0226.github.io/sea-game/](https://fumoto0226.github.io/sea-game/)

這是企劃中「Section 2：經營遊戲」的目前原型，主要測試玩家能否看懂建造、種植、賣貨、招募魚人和升級的流程。開始前可按「重新開始」清除本機舊進度。遊戲進度保存在目前瀏覽器，不會同步到其他裝置。

## 試玩流程

1. 按提示逐步建好蘋果農場。
2. 開始經營後，按下生產按鈕種蘋果。
3. 集滿第一箱後賣出蘋果，換取金幣。
4. 用金幣招募魚人，觀察不同角色的效果。
5. 繼續經營並嘗試升級農場。

目前第一箱需要 30 個蘋果，之後每箱 50 個；每箱基礎收入為 50 金幣。魚人價格、效果和遊玩節奏仍在測試中，請把數值視為原型設定。

## 目前範圍

- 建造步驟採用「每次點擊完成一個部件」，並提供逐步提示。
- 關鍵操作會以動畫或提示對話引導；支援簡體中文與日文切換。
- 建造、手動生產、賣貨和招募有不同的音效回饋。
- 金蘋果效果持續 20 秒。
- 目前聚焦個人經營與建設體驗；排行榜及海上城市總覽不在這個原型的主要流程內。

## 給試玩者的回饋

請特別留意：你是否知道下一步要做什麼？你能否理解賣蘋果、招募魚人和升級農場如何幫助工場發展？有哪一步讓你覺得等待太久、操作太多或看不懂？

## 本機執行

不需要安裝依賴。在此資料夾執行：

```sh
python3 -m http.server 5173
```

然後開啟 `http://localhost:5173/`。直接以 `file://` 開啟可能無法正常載入所有素材。
